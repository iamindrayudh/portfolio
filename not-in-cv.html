Game modding from before any of this was a résumé.

1. GTA: San Andreas — CLEO Modding

  • Modified CJ’s appearance, outfits, and character textures using TXD Workshop.
  • Created custom CLEO scripts using Sanny Builder for vehicle spawning, teleportation, cheat menus, super-jump, and wanted-level manipulation.
  • Extracted and replaced character, vehicle, and world assets using IMG Tool 2.0.
  • Customized in-game text and notifications using GXT Editor and .fxt resources.
  • Experimented with ASI Loader to load compatible plugins and extend gameplay functionality.

2. EA Sports Cricket 07 — Game Patching

  • Extracted and repacked game archives using BIGGUI and edited .fsh textures using FSHed.
  • Created custom team jerseys, half-sleeve kits, sponsor graphics, player face packs, and pitch textures using Adobe Photoshop.
  • Updated player attributes, squads, line-ups, and IPL-style tournaments using Player Editor and roster tools.
  • Modified stadium and pitch assets to update the game’s visual presentation.
  • Experimented with batting stroke animations, shot sequences, and timing adjustments using community modding tools.

3. WWF Raw PC / WWE — Wrestling Modding

  • Created custom wrestler appearances and attire by modifying character textures and compatible model assets.
  • Extracted and replaced supported game resources using XpkImg.
  • Recreated signature moves, finishers, and taunts by combining existing animations and move sequences.
  • Inspected binary resources using HxD Hex Editor to investigate game data and configuration.
  • Prepared custom entrance videos using RAD Video Tools for compatible Bink video playback.
